Mini Project 1



This program implements the Vigenere cipher and a brute force password cracker.



Files



- main.cpp - main program

- MP1\_dict.txt - dictionary used for password cracking



 How to Run



Compile and run main.cpp. Make sure MP1\_dict.txt is in the same directory as the program.



The program has three options:



1\. Encrypt a message

2\. Decrypt a message

3\. Crack an encrypted message



For encryption and decryption, enter the message and key when prompted.



For password cracking, enter the ciphertext, key length, and length of the first word. The program will try all possible keys and print any possible matches found using the dictionary.
